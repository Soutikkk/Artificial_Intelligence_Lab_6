# Artificial Intelligence Lab 6

This repository contains Python programs developed for Artificial Intelligence lab assignments, specifically focusing on classification algorithms: **K-Nearest Neighbors (KNN)** and **Support Vector Machines (SVM)**[cite: 1].

## Repository Structure
* **`KNN Program.py`**: Implementation of the K-Nearest Neighbors classification algorithm[cite: 1].
* **`Optional KNN Program.py`**: An alternative or advanced implementation of the KNN algorithm[cite: 1].
* **`SVM Program.py`**: Standard implementation of a Support Vector Machine classifier[cite: 1].
* **`SVM Comparing Linear and RBF Kernels.py`**: A comparative script evaluating the performance and decision boundaries of SVM using Linear versus Radial Basis Function (RBF) kernels[cite: 1].

## Prerequisites
To run these scripts, ensure you have Python installed along with standard machine learning and data science libraries:
* Python 3.x
* NumPy
* Pandas
* Scikit-Learn
* Matplotlib / Seaborn
